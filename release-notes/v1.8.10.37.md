# Windows 1.8.10.37：界面重做（工作台壳层 + 六页重排）

## 本次更新

界面整体重做。功能、配置项与调用链都未改动：解析、下载、批量、书架、转换的行为与上一版一致。

- **壳层**：顶部 6 个标签改为左侧导航栏（208px），标题栏横向通栏，底部新增状态条（后台任务状态点、保存目录、版本号）。切页时内容区宽度不再随标签文案变化。
- **视频解析**：链接输入与解析结果合并到同一面板，解析完结果紧接着展开；未解析时是带引导的空态。作品信息分四层（标题 / 作者与类型徽章 / 画质与时长等元信息 / 点赞评论分享），主操作只保留「下载」，其余收为图标按钮。
- **下载任务**：新增分段筛选（全部 / 进行中 / 已完成 / 失败，计数就是筛选），失败任务不必再在长表里肉眼找；列宽按实测文本重算（固定列合计 812px），状态列只写状态、失败原因进悬停提示；文件名列改单行省略，避免长文件名把行高撑成两三行；运行日志面板可折叠。
- **设置**：从「每项一张卡片」改为分组面板 + 设置行，右侧控件统一宽度对齐；账号区一个平台一行，状态用徽章表达。
- **WebP 转 MP4**：左右两栏（输入队列 / 转换设置）+ 底部结果区，参数与结果同屏可见；列表内操作收为图标按钮。
- **批量下载 / 漫画阅读器**：纳入新壳层；批量表的数值列改固定宽度，加载过程中不再左右抖动；漫画的搜索筛选排序与书架合并进同一块面板。
- **本地视频（保留并适配新壳层）**：下载完成的视频自动入库、卡片墙、搜索排序、续播进度、倍速/全屏播放器，与上一版功能一致；页面换成新壳层的页头 + 面板布局。
- **修复设置页数字输入框**：上一版把「每文件连接数 / 同时下载数」压到 96px，而该控件自带两个 31px 箭头按钮，数字区只剩 20px（数字贴左缘、再多一位就被裁）。现统一为 132px，与同列下拉框等宽，数字区 60px。
- **视觉**：加入静态氛围层 —— 画布两团角落光晕（跟随强调色）、面板渐变描边与顶部受光高光、页头渐变标题与强调色竖条、侧栏选中项渐变底。全部是静态绘制、无装饰动画；光晕按「尺寸 + 主题 + 强调色」缓存成位图，滚动时只做一次位图拷贝，不引入高频重绘。

## 安装

- 安装版：`视频下载器-1.8.10.37-setup.exe`（约 137 MB），双击按向导安装到 `%LOCALAPPDATA%\Programs\视频下载器`。
- 免安装：直接运行 `视频下载器.exe`（单文件，约 111 MB）。
- 升级现有版本不需要卸载，安装包会原地替换程序文件；`config.json`、`edge_profile*`、书架与下载文件都保留。

## 验证

- 全套 136 项单元测试通过，含任务表操作列必须在最左、列宽预算、漫画与转换窗口集成、解析失败重试、视频库持久化等回归项。
- 本地视频实测：用 ffmpeg 生成测试视频走完整链路 —— 入库、首帧截取封面、播放器加载（时长 3000ms）、播放位置从 0 推进到 3000、进度落盘。
- 界面冒烟脚本覆盖：壳层与导航切换、深浅主题往返、强调色切换、任务入队与移除后表格/空态切换、七个页面关键控件可达。
- 真实窗口逐页切换（深色 + 浅色各一轮）无异常；七个页面均已截图人工核对。
- 打包产物核对：从 exe 的 PYZ 中取出各模块 code 对象，逐项确认新界面符号存在、已删除的旧模块不在包内。
- 安装包实测：静默安装 → 比对安装后 exe 的 SHA256 与源文件一致 → 启动确认日志出现「启动 v1.8.10.37」→ 静默卸载，注册表项清除、进程无残留。

## 已知边界

- 首次启动仍是默认窗口 1280×720；更窄的窗口下任务表会出现横向滚动条，核心的「操作」列固定在左侧始终可见。
- 浅色主题的光晕刻意压得很淡，若觉得氛围不够可等后续版本提供强度设置。
- 本次只发 Windows 桌面端，Android 端未改动。
