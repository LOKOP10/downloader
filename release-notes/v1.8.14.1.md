# Windows 1.8.14.1：界面重做 + 合入长期分支的安全修复

## 本次更新

两件事合到一起：桌面端界面整体重做，以及把长期停留在
`audit/android-full-20261015` 分支上的 12 个提交并入 main。此前 main
缺少五项高危修复与本地视频播放器。

功能与配置项未改动：解析、下载、批量、书架、转换、播放的调用链与上一版一致。

## 一、合入的高危修复（此前缺失）

- **配置损坏会静默清空用户数据**：config.json 解析失败时旧实现静默回退默认值，
  之后用户再切任意开关就触发保存，原文件被默认值整体覆盖，Cookie 与下载目录
  永久丢失。现在读不懂的配置会先改名备份为 `.corrupt`，用户数据不会丢。
- **配置顶层非对象导致程序永久起不来**：被写成 `[]`、`null`、数字或字符串时，
  `.items()` 抛 AttributeError 而旧 except 覆盖不到。现在校验根节点必须是对象，
  并把越界/非法的数值项收敛到合法区间；保存改为先写临时文件再原子替换，进程被杀
  也不会留下半截 JSON。
- **无 Content-Length 时半截文件被判定为已完成**：服务端发一半就断开时旧实现会把
  半截文件改名成成品并标记「已完成」，静默产出坏文件。现在无长度且无 chunked 终止块
  一律判失败，不再当成品落盘。
- **伪域名诱骗 Cookie 外发**：旧实现用 `keyword in host` 子串匹配，
  `douyin.com.evil.cn`、`evilbilibili.com`、`notx.com` 都会被认成官方站点，
  进而把用户 Cookie 发往不可控域名。现改为按域名标签边界匹配；顺带显式补全
  `douyinvod.com` / `douyinpic.com`（它们此前靠子串侥幸命中，严格匹配后必须列出，
  否则抖音视频缺 Referer 会 403）。
- **启动期 int() 转换无保护**：`max_concurrent` 被改成 `"abc"` 时 ValueError 让主窗口
  构造即崩。现在回退默认值。

版本号顺带收敛一致：分支上 exe 资源写的是 1.8.14.0、安装包写的是 1.8.10.42，
现在三处文件与资源字符串统一为 1.8.14.1。

## 二、界面重做

- **壳层**：顶部标签改为左侧导航栏（208px，7 项），标题栏横向通栏，底部新增状态条
  （任务状态点、保存目录、版本号）。切页时内容区宽度不再随标签文案变化。
- **视频解析**：链接输入与解析结果合并到同一面板，解析完结果紧接着展开；未解析时是
  带引导的空态。作品信息分层（标题 / 作者与类型徽章 / 画质时长等元信息 / 互动数），
  主操作只保留「下载」，其余收为图标按钮。
- **下载任务**：新增分段筛选（全部 / 进行中 / 已完成 / 失败，计数就是筛选）；列宽按
  实测文本重算，状态列只写状态、失败原因进悬停提示；文件名列单行省略，避免长文件名
  把行高撑成两三行；运行日志面板可折叠。
- **设置**：从「每项一张卡片」改为分组面板 + 设置行，右侧控件统一宽度对齐；账号区
  一个平台一行，状态用徽章表达。
- **WebP 转 MP4**：左右两栏（输入队列 / 转换设置）+ 底部结果区；列表内操作收为图标按钮。
- **批量下载 / 漫画阅读器**：纳入新壳层；批量表数值列固定宽度，加载中不再左右抖动；
  漫画的搜索筛选排序与书架合并进同一块面板。
- **本地视频**：随分支一并回到界面上 —— 下载完成的视频自动入库、卡片墙、搜索排序、
  续播进度、倍速/全屏播放器，功能与分支版一致，页面换成新壳层的页头 + 面板布局。
- **修复设置页数字输入框过窄**：上一版把「每文件连接数 / 同时下载数」压到 96px，
  而该控件自带两个 31px 箭头按钮 + 5px 间距，数字区只剩 20px（数字贴左缘、多一位
  就被裁）。现统一为 132px 并显式左对齐，与同列下拉框等宽，数字区 60px。
- **视觉**：静态氛围层 —— 画布两团角落光晕（跟随强调色）、面板渐变描边与顶部受光
  高光、页头渐变标题与强调色竖条、侧栏选中项渐变底。全部静态绘制、无装饰动画；
  光晕按「尺寸 + 主题 + 强调色」缓存成位图，滚动时只做一次位图拷贝。

## 安装

- 安装版：`视频下载器-1.8.14.1-setup.exe`（约 137 MB），双击按向导安装到
  `%LOCALAPPDATA%\Programs\视频下载器`。
- 免安装：直接运行 `视频下载器.exe`（单文件，约 111 MB）。
- 升级现有版本不需要卸载，安装包会原地替换程序文件；`config.json`、`edge_profile*`、
  书架与下载文件都保留。

## 验证

- 全套 **182 项单元测试通过**（合并前 136 项，分支带来 46 项），覆盖任务表操作列
  必须在最左、列宽预算、漫画与转换窗口集成、解析失败重试、视频库持久化、配置损坏
  备份、伪域名拒绝、半截文件判定等。
- 安全修复实测：损坏的 config.json 被备份为 `.corrupt` 且保存后未被覆盖；根节点为
  数组时不崩；`max_concurrent="abc"` 收敛为 3、`segment_connections=999` 收敛为 32；
  5 个伪域名（含 `douyin.com@evil.cn` 这种 userinfo 伪装）全部拒绝，31 个真实
  CDN/API 域名全部识别。
- 本地视频实测：ffmpeg 生成测试视频走完整链路 —— 入库、首帧截取封面、播放器加载
  （时长 3000ms）、播放位置从 0 推进到 3000、进度落盘。
- 界面冒烟脚本覆盖壳层与导航切换、深浅主题往返、强调色切换、任务入队与移除后
  表格/空态切换、七个页面关键控件可达。
- 打包产物核对：从 exe 的 PYZ 中取出各模块 code 对象，确认新界面符号存在、
  已删除的旧模块不在包内。
- 启动验证：日志出现「启动 v1.8.14.1」。

## 已知边界

- 首次启动仍是默认窗口 1280×720；更窄的窗口下任务表会出现横向滚动条，核心的
  「操作」列固定在左侧始终可见。
- 浅色主题的光晕刻意压得很淡，若觉得氛围不够可等后续版本提供强度设置。
- 安装脚本现在同时兼容单文件版与文件夹版（onedir）：有 `_internal` 就一并安装，
  没有就跳过。本次发布的仍是单文件版。
- 本次一并合入的 Android 端改动（漫画书架与离线阅读、禁漫多章少页修复）属于
  1.0.49，未在本机做真机验证。
