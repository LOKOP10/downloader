# Windows 1.8.15.0：新增 MP4 转 GIF 页面

## 本次更新

桌面端新增原生「MP4 转 GIF」页面，位于左侧导航「WebP 转 MP4」之后。
解析、下载、批量、书架、播放与 WebP 转换的既有调用链不变。

## 一、MP4 转 GIF

- **输入**：多选文件或直接拖入；每个 MP4 独立转换为同名 `.gif`，失败项不会阻断批量后续任务。
- **片段截取**：可设置起始时间与转换时长，支持秒数、`分:秒`、`时:分:秒`；时长留空表示从起始时间到结尾。
- **输出参数**：
  - 帧率 10 / 15 / 20 / 24 帧每秒；
  - 宽度 320 / 480 / 640 px 或原宽（原宽超过 1920 时自动缩小）；
  - 颜色数 256 / 128 / 64；
  - Bayer 抖动或无抖动；
  - 无限循环，或只播放一次。
- **编码方式**：FFmpeg 两遍调色板（palettegen + paletteuse），避免逐帧独立调色造成闪烁；
  音频、字幕与数据流一律丢弃，只保留视频画面。
- **复用组件**：使用设置页已有的 ffmpeg，不新增强制依赖；缺失时按提示到「设置 → 合并组件」下载。
- **取消与发布**：后台线程转换，可随时取消；输出先写入目标目录下的临时目录，成功后才原子发布。
  失败或取消不会留下半成品，也不会修改源视频；默认不覆盖同名 GIF。
- **资源上限**：单文件 8 GiB、输出宽 ≤1920、时长 ≤300 秒、≤1500 帧；超限时明确报错，不静默截断。
- **结果操作**：结果列表显示尺寸与帧数，可用系统默认图片查看器预览，或直接打开输出目录。

## 安装

- 安装版：`视频下载器-1.8.15.0-setup.exe`（约 137 MB），双击按向导安装到
  `%LOCALAPPDATA%\Programs\视频下载器`。
- 免安装：直接运行 `视频下载器.exe`（单文件，约 111 MB）。
- 升级现有版本不需要卸载；`config.json`、`edge_profile*`、书架与下载文件都保留。

## 验证

- 全套 **206 项测试通过**（32 项子测试），覆盖引擎真实 FFmpeg 编码、中文与空格路径、
  起始/时长截取、缩放与循环、覆盖策略、取消清理、资源上限，以及界面队列、参数传递、
  批量失败继续、关闭不阻塞与主窗口真实端到端转换。
- 打包版本机实测：添加 1.2 秒测试视频 → 输出 GIF 480×320、18 帧、无限循环，
  界面结果区显示「完成 · test.gif · 480×320 · 18 帧」。
- 打包版启动日志出现「启动 v1.8.15.0」，转换页导航与全部设置项正常显示。

## 已知边界

- 本次未在「本地视频」页增加右键「转为 GIF」快捷入口，入口仍是导航页手动添加或拖入。
- 长视频/超大分辨率未做专项性能测试，受 300 秒、1500 帧与 1920 宽上限保护。
- 单文件版启动仍需系统 TEMP 可写。
