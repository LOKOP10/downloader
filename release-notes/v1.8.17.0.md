# Windows 1.8.17.0：新增 YouTube 视频解析

## 本次更新

桌面端新增 **YouTube 单视频解析**，接入现有的「解析 → 选画质 → 下载 → ffmpeg 合并」流程。
另外把上一版（1.8.16.0）的抖音图文动图改动一并纳入本次发布。

## 一、YouTube 解析

- **链接形态**：`watch`、`shorts`、`live`、`music.youtube`、`embed`、`youtu.be` 短链，以及带 `list=` 的单集链接（只取当前视频）。
- **画质档位**：按视频高度聚合，最多 8 档（2160p / 1440p / 1080p / 720p / 480p / 360p / 240p / 144p），每个档位自动配最高码率的 m4a 音轨；档位标签标注帧率与编码（如 `2160p · 25fps · AV1`）。
- **容器约束**：只选 mp4 容器（视频 `avc1` 优先，其次 `av01` / `vp9`；音频 `m4a`），保证 ffmpeg 能 `-c copy` 合并进 mp4，不重新编码。
- **解析实现**：用 `yt-dlp` 只负责取播放格式（含 nsig 签名与 JS 挑战），下载、分块、合并仍由本项目的下载器完成，不引入第二套下载逻辑。
- **代理**：解析与下载都走 Windows 系统代理，和其余平台一致。
- **边界处理**：播放列表、频道、搜索结果在本地直接给出中文提示，不展开整页；年龄限制、会员专享、私享视频、视频不可用、网络超时、签名求解失败等错误都转成中文提示。
- **界面**：平台支持行加入 YouTube；YouTube 视频的第三个统计位显示「观看」而不是「分享」。
- **依赖**：新增 `yt-dlp` 与 `yt-dlp-ejs`，打包时随 exe 一起分发，运行期不需要联网拉取组件。

## 二、1.8.16.0：抖音图文动图转 GIF

- 抖音图文作品解析后自动补齐 Live Photo 的视频轨，并转成 GIF；静态图与动图各走各的，互不阻塞。
- 图文作品的视频轨改用浏览器详情接口补齐，减少缺轨。


## 三、界面

- 桌面端界面回到「顶部标签导航 + 32px 紧凑自绘标题栏」布局：导航占一行，内容区宽度不再随标签文案变化；明暗切换按钮固定在右上角。
- 控件圆角、字号、间距恢复为上一轮的取值（4/6/10/14/18 圆角体系中的 6/10/14/18，正文 14px，页面左右留白 36px）。
- 状态条恢复为 26px。
## 安装

- 安装版：`VideoDownloader-1.8.17.0-setup.exe`（约 146 MB），双击按向导安装到
  `%LOCALAPPDATA%\Programs\视频下载器`。
- 免安装：直接运行 `VideoDownloader-1.8.17.0.exe`（单文件，约 120 MB）。
- 升级现有版本不需要卸载；`config.json`、`edge_profile*`、书架与下载文件都保留。
- YouTube 1080p 以上是音视频分离，需要在「设置 → 合并组件（ffmpeg）」下载一次 ffmpeg；与 B 站 DASH 合并共用同一个组件。

## 验证

- 全套 **271 项测试通过**（46 项子测试），新增 56 项 YouTube 解析测试，覆盖域名识别、档位选择、字段映射、错误分支与平台分发。
- 解析矩阵实测：watch / shorts / music / embed / youtu.be / watch+list 各 8 档并带音轨；播放列表、频道、搜索在 0 秒内被本地拦截；失效视频 2.3 秒返回中文提示。
- 端到端下载实测：1080p 合并后 `h264 1920x1080 25fps` + `aac`；720p 文件 29.9 MB、`h264 1280x720 25fps` + `aac`，速度 12–15 MB/s。
- 打包版本机实测：启动日志 `启动 v1.8.17`，界面解析 `Rick Astley - Never Gonna Give You Up` 成功，显示 8 档画质与「18.3亿 观看」，日志 `解析成功 youtube … 用时 5.27s | 画质 8 档`。
